# 红果自动跳广告（Android）

基于 Android **无障碍服务（AccessibilityService）** 的「红果短剧」广告自动跳过工具。
红果会自动连播剧集（包括自动接播下一页广告），本应用只负责一件事：
**在广告可以划走的那一刻，自动上滑把广告划掉**，横竖屏全屏通用，解放双手追剧。

> 需要 Android 8.0（API 26）及以上。

## 功能

- **智能跳广告**（默认开启）：每秒读屏一次，剧集连播完全不干预；检测到广告时——
  - 出现“上滑继续观看剧集”提示 → 立即上滑划走（横竖屏全屏通用）
  - “N秒后可继续上滑”倒计时中 → 等待
  - 只有“广告”标识、无倒计时（且不是剧集页）→ 上滑尝试划走（被拦截则冷却后重试）
- 悬浮球自动出现：开启无障碍服务即自动弹出（首次需授予悬浮窗权限），点 ▶/⏸ 开始或停止，可拖动，长按隐藏
- 传统定时模式：关闭「智能跳广告」后按固定间隔盲翻（适合信息流页面），2~600 秒可调
- 仅目标应用在前台时才动作，不影响其他应用的正常使用
- 目标包名可修改（国内版默认 `com.phoenix.read`，海外版为 `com.phoenix.read.oversea.gp`）
- 「测试一次上滑」按钮，用于快速验证手势是否生效

## 构建

### 方式一：Android Studio（推荐）

1. 安装 Android Studio（Hedgehog 或更新版本，需含 JDK 17）
2. `File → Open` 打开本项目根目录，等待 Gradle Sync 完成
3. 手机打开「开发者选项 → USB 调试」并连接电脑
4. 点击 Run ▶，安装到手机

### 方式二：GitHub Actions 云端打包（本地无需任何环境）

1. 在 GitHub 新建仓库，把整个项目 push 上去
2. 进入仓库的 **Actions** 页面，等待 `Build APK` 工作流跑完
3. 在**最新一次绿勾运行**页面底部的 **Artifacts** 下载 `hongguo-autoswipe-v版本号-apk`（文件名自带版本号，认准最新版本），解压出 `app-debug.apk` 传到手机安装
4. 装好后打开 App，主界面状态区会显示当前安装版本号，确认和 Actions 里的最新版本一致

### 方式三：命令行（已配好 Gradle Wrapper）

```bash
gradlew.bat assembleDebug        # Windows
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

## 使用步骤

1. 安装并打开「红果自动翻页」
2. 点击「① 开启无障碍服务」，在系统设置里找到「红果自动翻页」并允许，悬浮球会自动出现
3. 打开红果短剧，正常观看（剧集会由红果自动连播）
4. 点击悬浮球 **▶** 开始自动跳广告，**⏸** 停止，**长按**悬浮球可隐藏

## 效果不对？排查

| 现象 | 处理 |
| --- | --- |
| 悬浮球不出现（小米/红米 HyperOS/MIUI） | 打开 App 看状态区哪项未就绪；系统设置 → 应用设置 → 应用管理 → 红果自动翻页 → 权限管理：允许「显示悬浮窗」「后台弹出界面」，省电策略设为「无限制」，服务被杀时在最近任务里下拉锁定 |
| 主界面没有某个开关 / 行为和说明不符 | 大概率装的是旧版 APK：看主界面「当前安装版本」是否为最新（Actions 产物文件名自带版本号），重新下载最新产物覆盖安装 |
| 某个广告一直没被划走 | 确认「智能跳广告」和「自动等广告」都开启；若该广告既无倒计时文案、也无“广告”标识、也无“上滑继续观看”提示，请截图反馈识别不到的样子 |
| 广告期间上滑了好几次才划走 | 正常保护机制：倒计时未结束的上滑会被红果拦截（无副作用），应用每 2.5 秒重试，直到“上滑继续观看”提示出现成功划走 |
| 广告期间还在尝试滑动、被顶回来 | 确认主界面「自动等广告」已开启；个别广告样式没有倒计时文案，此时会按正常间隔翻页 |
| 翻页没反应 | 先点主界面「测试一次上滑」验证手势是否生效；确认包名与手机上安装的红果版本一致（可用 `adb shell dumpsys window \| findstr mCurrentFocus` 查看当前前台包名） |
| 服务开着却自动停了 | 国产 ROM 会杀后台：小米请开启「自启动」并在最近任务里锁定；华为/荣耀请把启动管理改为「手动管理」，允许后台活动 |
| 悬浮球出不来 | 系统设置 → 应用 → 红果自动翻页 → 显示在其他应用上层，允许 |
| 卸载/更新后失效 | 系统限制，需要重新开启无障碍服务 |
