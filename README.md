# 红果自动翻页（Android）

基于 Android **无障碍服务（AccessibilityService）** 的「红果短剧」自动上滑翻页工具：
当红果处于前台时，按设定间隔模拟一次上滑手势，自动切换到下一个视频/剧集，解放双手。

> 需要 Android 8.0（API 26）及以上。

## 功能

- 定时自动上滑，默认 20 秒一次，2~600 秒可调
- 仅目标应用在前台时才动作，不影响其他应用的正常使用
- 间隔带少量随机浮动，避免过于机械
- **悬浮球**：在红果里直接点 ▶/⏸ 开始或停止，可拖动，长按隐藏
- 目标包名可修改（国内版默认 `com.phoenix.read`，海外版为 `com.phoenix.read.oversea.gp`）
- 「测试一次上滑」按钮，用于快速验证手势是否生效

## 构建

### 方式一：Android Studio（推荐）

1. 安装 Android Studio（Hedgehog 或更新版本，需含 JDK 17）
2. `File → Open` 打开本项目根目录，等待 Gradle Sync 完成
3. 手机打开「开发者选项 → USB 调试」并连接电脑
4. 点击 Run ▶，安装到手机

### 方式二：GitHub Actions 云端打包（本地无需任何环境）

1. 在 GitHub 新建仓库，把整个项目 push 上去
2. 进入仓库的 **Actions** 页面，等待 `Build APK` 工作流跑完
3. 在该次运行页面底部的 **Artifacts** 下载 `app-debug.apk`，传到手机安装

### 方式三：命令行（已配好 Gradle Wrapper）

```bash
gradlew.bat assembleDebug        # Windows
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

## 使用步骤

1. 安装并打开「红果自动翻页」
2. 点击「① 开启无障碍服务」，在系统设置里找到「红果自动翻页」并允许
3. 回到应用，设置翻页间隔，打开「显示悬浮球」（首次会引导授予悬浮窗权限）
4. 打开红果短剧，进入任意竖屏视频/短剧播放页
5. 点击悬浮球 **▶** 开始自动翻页，**⏸** 停止，**长按**悬浮球可隐藏

## 效果不对？排查

| 现象 | 处理 |
| --- | --- |
| 翻页没反应 | 先点主界面「测试一次上滑」验证手势是否生效；确认包名与手机上安装的红果版本一致（可用 `adb shell dumpsys window \| findstr mCurrentFocus` 查看当前前台包名） |
| 服务开着却自动停了 | 国产 ROM 会杀后台：小米请开启「自启动」并在最近任务里锁定；华为/荣耀请把启动管理改为「手动管理」，允许后台活动 |
| 悬浮球出不来 | 系统设置 → 应用 → 红果自动翻页 → 显示在其他应用上层，允许 |
| 卸载/更新后失效 | 系统限制，需要重新开启无障碍服务 |
